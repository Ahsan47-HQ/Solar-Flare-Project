# Phase 2: completed model rebuild

The Phase 2 results were trained on the shared Phase 1 arrays and newly verified 24-hour labels. There are 17 saved full-data runs: four model families × two feature sets × two generalization splits, plus one random-split XGBoost leakage diagnostic. The model families are Logistic Regression, Random Forest, XGBoost, and a small ANN. The [result table](reports/phase2/classical_model_results.md), [run manifest](reports/phase2/experiment_manifest.json), and [reload audit](reports/phase2/model_reload_verification.md) are current.

Run `.\.sfd\Scripts\python.exe -u run_rebuild_matrix.py --phase phase2` from the repository root to resume or reproduce training. Models, validation and test probabilities, row IDs, configs, and metrics are saved under `data/rebuild/runs/phase2/`. The model directory is shared locally and ignored by Git. Publish reports with `.\.sfd\Scripts\python.exe publish_rebuild_reports.py` after `rebuild_evaluate.py` passes.

XGBoost uses CUDA with depth 3, 64 histogram bins, at most 180 trees, two CPU workers, and validation PR-AUC early stopping. Random Forest uses one worker. The ANN uses 32 and 16 hidden units with validation PR-AUC early stopping on CPU. The native Windows TensorFlow build does not expose CUDA; do not claim GPU training for the ANN. The XGBoost tree count was selected by early stopping. A bounded [validation-only sensitivity study](reports/phase2/validation_sensitivity.json) compared depths 2, 3, and 4, plus ANN widths 16/8, 32/16, and 64/32 on baseline features in both splits. It did not select or rescore a test model; the verified main matrix remains the reported result.

The random-split score measures the effect of heavily overlapping windows and is not evidence of independent-region skill. All classification thresholds were chosen by validation F1. See [REBUILD.md](REBUILD.md) for input hashes, cohort rules, and test results.
